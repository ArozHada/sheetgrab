3 Map columns to extraction rules

SheetGrab reads row 1 of your tab as column headers. For each column, pick what it should look for on the page. Keyword rules look for the label (e.g. “Apply by:”) and take the value right after it, or on the next line.

Make sure my Sheet has these columns

Missing ones are added to row 1 and linked to the right rule when you click Save settings. If a column disappears later, SheetGrab re-creates it the next time it has a value for it. Columns are never deleted.
